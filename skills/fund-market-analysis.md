# Fund Market Analysis

## Overview

使用内置 Python 脚本查询并分析中国公募基金数据，支持：

- 基金搜索（名称 / 拼音 / 代码）
- 历史净值分析
- 盘中实时估值
- 区间收益、年化收益、年化波动、最大回撤
- 风险等级判断
- 多基金对比报告
- “我的基金”微信式简洁快报
- 大盘市场分析报告（指数 + 资金流 + 财经快讯 + 持仓估值，AI 撰写）

估值策略按基金类型分流（三级降级）：

1. **东财官方估值接口**  
   调用 `fundgz.1234567.com.cn`，优先使用 `gsz / dwjz` 自行计算当日估值涨幅，并过滤非当日数据与明显异常值。**普通基金优先走此级**。

2. **持仓加权估值**  
   读取基金前十五大持仓，按市场分别取实时行情计算盘中估值。持仓市场通过东财行情链接 `unify/r/<市场ID>.<代码>` 权威识别（不靠代码格式猜，避免韩股 6 位码误匹配同码 A 股）：
   - **A股 / 港股 / 美股**：走腾讯行情（境内接口，快且稳）。
   - **台 / 韩 / 日股**（东财无行情链接）：走 **Yahoo Finance**（搜索接口消歧 → chart 取最后两个有效收盘算单日涨跌；符号映射缓存到磁盘）。境外 HTTPS 接口，**全程可降级**：短超时(3.5s)、单只失败仅跳过、连续失败熔断、可用环境变量 `FUND_DISABLE_OVERSEA=1` 关闭。Yahoo 不可达时自动退化为「仅腾讯覆盖」。
   - 支持 ETF 联接基金穿透；带持仓与行情缓存。
   - **普通基金**：仅作官方估值失败时的兜底，非归一化加权和（保守）。
   - **QDII**：**优先走此级**（东财对 QDII 的官方估值严重滞后、常反映更早的海外交易日，不可靠）。按覆盖率归一化外推到整只基金，实测与实际估算吻合；覆盖率不足 15% 时不出测算值，降级到第 3 级。ISIN 码（如 `JP3684400009`）暂无法映射，跳过。

3. **上一交易日净值兜底**  
   若前两级均失败，则显示上一交易日涨跌，并标注“非实时”。

## Quick Start

脚本入口：

- `scripts/analyze_fund.py`
- `scripts/realtime_estimate.py`
- `scripts/market_data.py`（市场指数/资金流/快讯采集）

三个文件需位于同一目录下。

常用命令：

```bash
# 我的基金（微信快报）
python <base_dir>/scripts/analyze_fund.py --my-funds

# 查询指定基金
python <base_dir>/scripts/analyze_fund.py --codes 000001,110022

# 搜索基金
python <base_dir>/scripts/analyze_fund.py --search 沪深300

# 大盘市场分析报告（采集数据，由你撰写报告）
python <base_dir>/scripts/analyze_fund.py --market-report

# JSON 输出
python <base_dir>/scripts/analyze_fund.py --codes 000001 --format json

# 调试日志
python <base_dir>/scripts/analyze_fund.py --my-funds --verbose

Parameters
--my-funds：查询默认基金列表的当日估值快报
--market-report：采集大盘指数/资金流/财经快讯+持仓估值+组合透视，输出微信友好的市场数据简报（默认原样发给用户）
--news-limit：市场简报纳入的财经快讯条数，默认 8
--codes：基金代码，多个代码用英文逗号分隔
--search：按名称、拼音或代码搜索基金
--days：分析最近 N 个交易日，默认 90
--page-size：历史净值拉取条数，默认 200
--format：输出格式，支持 markdown / json
--selftest：探测各行情/估值数据源连通性（A股/美股/港股腾讯、东财估值与持仓、Yahoo 台股），排查部署环境哪个源不通
--verbose：输出调试日志到 stderr
Notes
仅依赖 Python 标准库，无需安装第三方依赖
缓存策略：行情/估值「每次实时拉取，零缓存」，保证当日估值反映当下行情；只缓存慢变数据——持仓（1 天，季度才变）、净值历史（4 小时，每天收盘才更新）、基金目录（6 小时，静态）。持仓缓存带 schema 版本号，解析逻辑升级后旧缓存自动失效重抓
慢变数据缓存只为减轻东财负载与提速，不影响实时性：当日估值 = 持仓构成 × 当下实时行情
若 QDII 覆盖率异常偏低或某市场持仓缺失，先跑 `--selftest` 确认对应数据源是否可达
非交易时段可能自动降级为“非实时”
QDII 优先用持仓测算（标注“持仓测算 覆盖X%”，按最新海外收盘 + 覆盖率归一化，仅供参考，受汇率/持仓季度滞后/覆盖率影响）；持仓不足时回退东财官方估值（标注“QDII估值 MM-DD”）再到非实时
台/韩/日股经 Yahoo 取价，可用 FUND_DISABLE_OVERSEA=1 关闭；关闭或不可达时这些持仓不计入覆盖
纯债、货币型不做持仓估值，直接兜底为上一交易日涨跌
ETF 联接基金支持穿透到底层 ETF 做估值
